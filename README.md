## 🚀 Overview

Tired of browsing endless websites just to find the perfect bag? Bag Haven is here to revolutionize the way you shop for bags! Our platform brings a seamless, interactive, and intelligent shopping experience, making it easier than ever to discover and purchase high-quality bags from anywhere.

🎒 Why is Bag Haven Unique?

- 🌟 Personalized Shopping Experience – Smart AI-based recommendations tailored to your style.
- 🏷 Exclusive Discounts & Deals – Get real-time updates on the best bag deals.
- 🔍 Advanced Filtering System – Sort by price, popularity, brand, and availability effortlessly.
- 📦 Hassle-Free Cart Management – Add, remove, and review purchases with ease.
- 🏪 Owner-Friendly Product Creation – Store owners can upload, edit, and manage their products effortlessly.
- 🔄 Real-Time Stock Updates – Stay updated with product availability in real-time.

## 🏗 Features
- 🛍 Beautifully Designed Storefront – A visually appealing UI with smooth user experience.
- 🔎 Smart Search with Fuse.js – Find bags instantly using fuzzy search.
- 🛒 Intuitive Cart System – Easily manage your selected products.
- 🏷 Discount Integration – View discounted prices alongside original rates.
- 🔄 Dynamic Sorting & Filtering – Find exactly what you need with precise filters.
- 🔐 Secure Authentication – Login and signup system powered by bcrypt & JWT.
- 🏪 Admin Dashboard for Store Owners – Seamlessly manage inventory and pricing.
- 📱 Mobile-Friendly Design – Fully responsive for a great shopping experience on any device.

## 🛠 Installation

```sh
##Backend Setup
# Clone the repository
git clone https://github.com/yourusername/bag-haven.git
cd bag-haven/backend

# Install dependencies
npm install

# Start the server
npm start

##Frontend Setup
cd ../frontend

# Install dependencies
npm install

# Run the Application
npm run dev
```

## 📚  Learning Goals
This project enhances your skills in:

- Full-Stack Development – Implementing a robust MERN stack e-commerce store.
- Real-Time Cart & Product Management – Using Express & MongoDB to manage user carts.
- Secure User Authentication – Using JWT & bcrypt for account protection.
- Interactive UI with Tailwind CSS – Creating a visually stunning shopping experience.
- AI-Powered Search & Recommendations – Leveraging Fuse.js for fast and intelligent searches.

## 🎯 Issues & Limitations
🚧 Scalability for Large Inventories – Optimizing performance for handling thousands of products efficiently.

🚧 Stock Syncing in Real-Time – Ensuring inventory updates remain instant and accurate.

🚧 Checkout & Payment Gateway – Implementing secure payment processing (upcoming feature!).
